# Frontend

`index.html` este build-ul frontend-ului cursului: https://github.com/Victoras23/impact_2_year_fe

Se poate folosi in doua feluri:
- prin Docker Compose: http://localhost:3000
- dublu-click pe `index.html` (backend-ul accepta si originea `null` a fisierelor deschise local)

In bara de sus alege lectia (de ex. "Lectia 2") ca sa apara catalogul si butonul de autentificare.
Adresa backend-ului implicita este http://localhost:8080.
